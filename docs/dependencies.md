# Зависимости: что добавлено и удалено в v2.0

Правило проекта: новая зависимость появляется только с обоснованием в этом файле.

## Добавлено

| Пакет           | Тип | Зачем                                                                                           | Почему не без него                                                                                                                                                                                                                                                                                                                     |
| --------------- | --- | ----------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `vitest@^3.2.7` | dev | Юнит-тесты чистой логики: язык, даты, отправка формы, пагинация слайдеров. Запуск — `npm test`. | Использует тот же `vite.config.ts` (алиасы `@/…`), не требует Babel/ts-jest и отдельной конфигурации. Ветка 3.x выбрана потому, что поддерживает установленный Vite 6; установка 4.x падает на ошибке npm 10 при разрешении peer-зависимостей (`Cannot read properties of null (reading 'edgesOut')`). В production-бандл не попадает. |

## Удалено

| Пакет                                                                                                                                                                                                  | Где               | Почему                                                                                                       |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------- | ------------------------------------------------------------------------------------------------------------ |
| `resend`                                                                                                                                                                                               | фронтенд, runtime | Серверный SDK почты; во фронтенде не импортировался.                                                         |
| `tsx`                                                                                                                                                                                                  | фронтенд, dev     | Запускал генератор дат юридических страниц; генератор удалён (даты — данные в `src/data/legalRevisions.ts`). |
| `ts-node`                                                                                                                                                                                              | фронтенд, dev     | Не использовался.                                                                                            |
| `eslint-plugin-import`, `eslint-import-resolver-typescript`, `eslint-plugin-prettier`, `eslint-plugin-react-refresh`, `eslint-config-prettier`, `eslint-flat-config-utils`, `globals`, `@types/eslint` | фронтенд, dev     | Установлены, но не подключены в `eslint.config.ts`.                                                          |
| `stylelint-prettier`                                                                                                                                                                                   | фронтенд, dev     | Не подключён в `stylelint.config.cjs`.                                                                       |
| `nodemailer`, `@types/nodemailer`                                                                                                                                                                      | сервер            | Заменён HTTP API Brevo.                                                                                      |
| `node-fetch`, `@types/node-fetch`                                                                                                                                                                      | сервер            | В Node 18+ есть глобальный `fetch` (Brevo уже вызывался через него).                                         |
| `body-parser`, `@types/body-parser`                                                                                                                                                                    | сервер            | Встроен в Express как `express.json()`.                                                                      |

Обновлено в пределах semver (`npm audit fix`): на сервере `express` 4.18.2 → 4.22.3, `morgan`,
`zod`. Оставшееся предупреждение `zod` требует мажорной версии 4 и касается больших коллекций с
ограничениями — схема из одного поля email ему не подвержена.

## Временные инструменты (не в проекте)

Использовались один раз при подготовке v2 и в `package.json` не добавлены:

- **sharp** — конвертация растровых картинок в WebP. Качество подбиралось для каждого файла как
  минимальное из q75–q90, при котором PSNR по премультиплицированному RGBA ≥ 40 дБ (фон секций —
  q85, чтобы тонкие цветные линии не теряли оттенок). Повторить:
  `npx sharp-cli --input <file> --output <dir> --format webp --quality <q>`.
- **Lighthouse, Playwright, axe-core** — замеры и проверки из `docs/v2-review.md`.
