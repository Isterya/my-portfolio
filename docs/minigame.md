# Миниигра: уместна ли и какая

## Вывод

**Да, но только на странице 404 и только по клику.** Главная страница — воронка «посмотрел работы →
написал». Игра на главной отвлекает от неё и добавляет вес. На 404 она превращает тупик в повод
вернуться на сайт, а для техлида, который из любопытства вбивает случайный URL (так делают чаще, чем
кажется), — показывает навыки: алгоритм, canvas, управление с клавиатуры и тача, доступность, code
splitting.

Игра: **«Путь домой»** — лабиринт, в котором светящаяся оранжевая точка (мотив маскота) ищет дорогу
к логотипу «BY». Победа ведёт на главную.

## За и против

| За                                                   | Против                                                      |
| ---------------------------------------------------- | ----------------------------------------------------------- |
| Запоминается: «у этого разработчика на 404 лабиринт» | Отвлекает от целевого действия, если стоит на главной       |
| Демонстрирует алгоритмы, canvas, ввод, a11y          | Дополнительный код, который надо поддерживать               |
| Возвращает потерявшегося посетителя на главную       | Риск для производительности, если грузится вместе с сайтом  |
| Поддерживает тон 404-страницы («You are lost»)       | Работодатель из консервативной компании может счесть лишним |

Минусы снимаются размещением (только 404), ленивой загрузкой по клику и тем, что основная кнопка «На
главную» остаётся главной.

## Рассмотренные варианты

| Вариант                           | Суть                                                                 | Оценка                                                                                                                                                      |
| --------------------------------- | -------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **«Путь домой» (лабиринт)**       | Сгенерированный лабиринт, дойти до логотипа; победа ведёт на главную | ✅ Смысл совпадает с 404, пошаговая — нет постоянного цикла отрисовки, управляется стрелками, свайпами и кнопками, генерация лабиринта — наглядный алгоритм |
| «Лови баги»                       | Ловить падающие «баги» скобкой `{ }`                                 | Динамично, но требует постоянного 60 fps цикла, сложнее сделать доступной, не связана с 404                                                                 |
| Пасхалка на главной (Konami code) | Скрытая игра на основном сайте                                       | Никто не найдёт без подсказки; код игры пришлось бы держать рядом с главной                                                                                 |

## Требования

**Производительность**

- Ноль байт в главном чанке и чанке главной страницы: игра — отдельный чанк, загружается только по
  клику «Сыграть» (предзагрузка при наведении или фокусе на кнопке).
- Бюджет чанка игры — до 6 КБ gzip, без новых зависимостей.
- Нет постоянного цикла: отрисовка только при изменении состояния, `requestAnimationFrame` — только
  на время анимации хода (≈120 мс).
- Canvas с учётом `devicePixelRatio`, перерисовка при ресайзе через `ResizeObserver`.

**Доступность**

- Управление: стрелки и WASD, свайпы, экранные кнопки-стрелки (настоящие `<button>` с подписями).
- Статус («Уровень 1», «Вы дома!») — через `aria-live`; у canvas — `role="img"` и описание.
- `prefers-reduced-motion`: ходы без анимации, без пульсации свечения.
- Escape закрывает игру и возвращает фокус на кнопку «Сыграть»; ссылка «На главную» доступна всегда.

**Локализация**

- Строки игры (en/ru/pl) лежат в модуле игры, а не в общих локалях, — чтобы не утяжелять главный
  чанк.

## Техническое решение

- `src/features/wayHome/` — изолированная фича:
  - `maze.ts` — чистые функции: генерация лабиринта (итеративный DFS / recursive backtracker с
    сидируемым ГПСЧ), проверка хода; покрыты тестами;
  - `WayHomeGame.tsx` — canvas, ввод, состояние уровня;
  - `strings.ts` — тексты на трёх языках.
- `Page404` — кнопка «Сыграть», `lazy()` + `Suspense` для игры.
- Размер лабиринта зависит от ширины экрана и растёт с уровнем.
- Лучший результат (минимум ходов) — в `localStorage` с `try/catch`.

## Критерии приёмки

1. `npm run build`: размеры `index-*.js` и `HomePage-*.js` не изменились, чанк игры ≤ 6 КБ gzip.
2. Lighthouse главной — без изменений; на 404 до клика сеть не запрашивает чанк игры.
3. Прохождение лабиринта только с клавиатуры и только касаниями (эмуляция мобильного).
4. При reduced motion нет анимаций; вкладка в фоне — ноль работы.
5. axe-core на 404 с открытой игрой — без нарушений.
