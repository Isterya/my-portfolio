# Дизайн и анимации v2.0 — предложения

> Только предложения. В коде дизайн не менялся: направление выбирает автор. Технические правки
> анимаций, которые не меняют внешний вид (reduced motion, пауза вне экрана, шов бегущей строки,
> повторное появление героя), сделаны в ветке реализации и описаны в `docs/v2-review.md`.

## Что сейчас

**Визуальный язык.** Светлый фон, Poppins, крупные заголовки с выделенным оранжевым градиентом
словом («My **Skills**»). Тёмные «стеклянные» секции (Skills, Price) с волнистым фоном и
3D-фигурами. Маскот — фигура в капюшоне со светящимися оранжевыми точками. Навбар — стеклянная
«таблетка», кнопки — оранжевые пилюли.

**Что работает и стоит сохранить:**

- узнаваемый оранжевый акцент и монограмма «BY»;
- контраст светлых и тёмных секций — у страницы есть ритм;
- мотив светящихся точек на маскоте — потенциальный фирменный элемент;
- аккуратные мелкие детали: декоративные штрихи у «Hello!», звёздочки у «My Price».

**Что мешает «продавать»:**

1. **Шаблонность первого экрана.** Композиция «Hello! → I’m Name, Role → цитата слева → 5 звёзд
   справа → человек на полукруге → две пилюли» широко тиражируется в бесплатных Figma-шаблонах
   портфолио. Техлид видит её не первый раз — это сигнал «джуниор собрал по шаблону».
2. **Доверие.** Безликий маскот вместо человека, «5 звёзд» без источника, «8+ проектов» при шести в
   портфолио, учебные проекты курсов на месте кейсов.
3. **Читаемость.** Основной текст `#98a2b3` (контраст 2,6:1), белый на оранжевом (2,5:1), на
   телефоне половина текста мельче 12 px (минимум — 8 px).
4. **Слайдеры прячут контент.** 15 навыков видны по 3 штуки с автопрокруткой, проекты — по 2, цены —
   бегущей строкой, которую невозможно сравнить. Рекрутер сканирует страницу 30–60 секунд и не будет
   ждать слайды.
5. **Два шрифта на три языка.** Poppins не содержит кириллицы — русская версия набрана Inter, то
   есть выглядит как другой сайт.
6. **Мобильная навигация** уезжает с первым экраном и не видна на тёмных секциях.

## Общие требования к любому направлению

Эти пункты не зависят от выбора стиля и закрывают находки аудита A11Y-2, RESP-1, RESP-2.

| Тема        | Требование                                                                                                                                                                                                                                |
| ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Контраст    | Основной текст ≥ 4,5:1, крупный ≥ 3:1. Белый на `#ff7f00` недопустим для текста: либо тёмный текст на оранжевом, либо более тёмный оранжевый.                                                                                             |
| Типографика | Одна гарнитура с латиницей, latin-ext (польский) и кириллицей; 2–3 начертания; self-hosting woff2. Основной текст на мобильном ≥ 16 px, вторичный ≥ 14 px, межстрочный 1,5. Шкала через `clamp()` вместо 6 ручных значений на брейкпоинт. |
| Навигация   | Фиксированная кнопка меню на мобильном с подложкой; переключатель языка внутри меню.                                                                                                                                                      |
| Контент     | Вместо слайдеров — сетки и списки. Кейсы в формате «задача → решение → результат» с метриками и ссылками на код. Резюме PDF и GitHub — на первом экране.                                                                                  |
| Форма       | Имя, email, сообщение, опционально бюджет и сроки; рядом — альтернативные каналы.                                                                                                                                                         |
| Доверие     | Только проверяемые цифры; реальное фото или последовательный персонаж; отзывы, если есть.                                                                                                                                                 |
| Темы        | Токены цвета в CSS custom properties — светлая и тёмная тема почти бесплатно.                                                                                                                                                             |

Варианты гарнитур с латиницей, latin-ext и кириллицей (все — OFL, вариативные): **Onest**, **Inter /
Inter Tight**, **Manrope**, **Geologica**, **Unbounded** (только для заголовков); моноширинный —
**JetBrains Mono**.

## Направление 1. «Инженерный минимализм»

**Для кого.** Прежде всего работодатели: техлиды, HR продуктовых компаний. Сайт сам становится
доказательством качества: быстро, доступно, аккуратно.

**Идея.** Типографика вместо иллюстраций, много воздуха, строгая сетка, кейсы с цифрами. Детали «из
мира кода»: моноширинные подписи (`01 / Work`), версии, номера разделов, честные метрики сайта
(Lighthouse, вес страницы) прямо в футере.

**Палитра (контраст на фоне `#FAFAF9`):**

| Роль                   | Цвет                                            | Контраст |
| ---------------------- | ----------------------------------------------- | -------- |
| Фон                    | `#FAFAF9`                                       | —        |
| Основной текст         | `#111827`                                       | 17:1     |
| Вторичный текст        | `#4B5563`                                       | 7,2:1    |
| Приглушённый текст     | `#6B7280`                                       | 4,6:1    |
| Акцент для текста и UI | `#C2410C` (тёмный оранжевый)                    | 5,0:1    |
| Фирменный оранжевый    | `#FF7F00` — только крупные декоративные акценты | —        |

Тёмная тема: фон `#0B0B0C`, текст `#EDEDED`, акцент `#FF8A1F`.

**Типографика.** Inter Tight / Onest для заголовков (плотный трекинг, 600), Inter / Onest для текста
(400/500), JetBrains Mono для подписей.

**Структура главной.**

1. Первый экран: имя, роль, одно предложение ценности, две кнопки («Кейсы», «Резюме PDF»), строка
   доказательств («Lighthouse 95+ · WCAG AA · EN/PL/RU»). Без маскота или с небольшим реальным фото.
2. Избранные работы: 3 карточки-кейса (скриншот в рамке устройства, стек, результат).
3. Что я делаю: услуги и стек компактным списком, сгруппированным по задачам.
4. Опыт: роли и результаты, без школы.
5. Цены: простая таблица пакетов.
6. Контакт.

**Графика.** 3D-фигуры и волнистый фон уходят; вместо них — тонкая сетка, аннотации, реальные
интерфейсы.

**Анимации.** Минимальные и функциональные: появление текста по словам на первом экране, hover-
состояния, View Transitions между главной и страницей кейса, прогресс таймлайна при скролле.

**Плюсы:** самый быстрый и доступный вариант, проще всего поддерживать, сильнее всего для
работодателей. **Минусы:** меньше «вау» для заказчиков, требует хороших кейсов. **Трудоёмкость:**
средняя — больше удаления, чем добавления; основная работа — контент.

## Направление 2. «Тёмный продукт» (эволюция текущего стиля)

**Для кого.** Заказчики (стартапы, агентства), которым нужен современный «премиальный» сайт, и
продуктовые компании.

**Идея.** Сохранить узнаваемое (оранжевое свечение, стекло, тёмные секции), но перейти в тёмную тему
целиком и собрать страницу как лендинг SaaS-продукта: bento-сетка, мягкие свечения, точная
типографика. **Фирменный элемент — «поле точек»:** светящиеся точки маскота превращаются в
интерактивный фон первого экрана (canvas, реагирует на курсор, грузится лениво, останавливается вне
экрана; при reduced motion — статичная картинка).

**Палитра (контраст на `#0A0A0B`):**

| Роль                 | Цвет                                                                 | Контраст |
| -------------------- | -------------------------------------------------------------------- | -------- |
| Фон                  | `#0A0A0B`                                                            | —        |
| Поверхность / стекло | `#141416`, `rgb(255 255 255 / 4%)` + граница `rgb(255 255 255 / 8%)` | —        |
| Основной текст       | `#F5F5F5`                                                            | 18:1     |
| Вторичный текст      | `#A1A1AA`                                                            | 7,7:1    |
| Акцентный градиент   | `#FFB547 → #FF7F00` — заголовки, свечения                            | —        |
| Кнопка               | оранжевая подложка `#FF7F00`, текст `#111111`                        | 7,5:1    |

**Типографика.** Geologica или Unbounded для заголовков, Inter для текста.

**Структура главной.**

1. Первый экран: крупный заголовок, поле точек, плавающие стеклянные «чипсы» со стеком.
2. Навыки — bento-сетка групп («Core», «Стили», «Состояние», «Инструменты») вместо 15 карточек в
   слайдере.
3. Проекты — крупные карточки с беззвучными превью-видео при наведении (ленивая загрузка).
4. Опыт — вертикальный таймлайн со «светящейся» линией прогресса.
5. Цены — сетка из 3 пакетов с выделенным «популярным», без бегущей строки.
6. Контакт — стеклянная карточка с формой.

**Анимации.** Богаче: «прожектор» под курсором на карточках (радиальный градиент через CSS-
переменные), параллакс 3D-фигур через scroll-driven animations, ступенчатое появление bento, лёгкие
«магнитные» кнопки. Всё — только `transform`/`opacity`, всё отключается при reduced motion.

**Плюсы:** эффектно, сохраняет узнаваемость, показывает продвинутые навыки (canvas, scroll-driven
animations). **Минусы:** `backdrop-filter` и свечения тяжелы для слабых телефонов — нужна
дисциплина; риск стать «ещё одним тёмным шаблоном». **Трудоёмкость:** средняя–высокая.

## Направление 3. «Тёплый персональный бренд»

**Для кого.** Малый бизнес и стартапы, которые ищут дружелюбного фрилансера; площадки, где важно
запомниться.

**Идея.** Личность — это продукт. Светлая тёплая палитра (крем, персик, оранжевый), маскот
перерисован в последовательного 2D-персонажа (вектор вместо 3D-рендера), который проводит по
странице: машет на первом экране, показывает на проекты, держит форму. Рисованные акценты (у сайта
они уже есть — штрихи у «Hello!»), скругления, «стикеры». Миниигра на 404 (см. `docs/minigame.md`)
естественно продолжает этот стиль.

**Палитра (контраст на `#FFF8F1`):**

| Роль                   | Цвет                          | Контраст |
| ---------------------- | ----------------------------- | -------- |
| Фон                    | `#FFF8F1`                     | —        |
| Основной текст         | `#1F1A17`                     | 16:1     |
| Вторичный текст        | `#5C4F45`                     | 7,5:1    |
| Ссылки и мелкий акцент | `#B54708`                     | 5,2:1    |
| Крупный акцент         | `#F26B1D`                     | —        |
| Поверхности            | `#FEB273` с текстом `#1F1A17` | 9,7:1    |

**Типографика.** Rubik или Unbounded для заголовков, Onest для текста.

**Структура главной.** История: «Привет» → «Что я делаю» (иллюстрированные услуги) → избранные
работы → «Как я работаю» (4 шага с ценами) → «Кто я» → контакт.

**Анимации.** Игривые, но лёгкие: SVG-анимации персонажа на CSS (без Lottie), пружинящие кнопки,
«отклеивание» стикеров при наведении, конфетти после отправки формы (с reduced motion — без них).

**Плюсы:** запоминается, выделяет среди фрилансеров. **Минусы:** менее «серьёзно» для крупных
работодателей; нужны иллюстрации (время или дизайнер); риск выглядеть несерьёзно. **Трудоёмкость:**
высокая.

## Анимации: что менять

### Принципы

1. **Только `transform` и `opacity`** (изредка `filter`). Никаких переходов `height`, `padding`,
   `width`, `top`, `font-size`: сейчас именно так «сжимается» навбар (перерасчёт layout каждый
   кадр), а точки слайдера анимируют `width`.
2. **Не `transition: all`.** Сейчас — в 13 местах; всегда перечислять свойства.
3. **Появление — один раз.** `viewport={{ once: true }}`; контент не должен снова прятаться при
   прокрутке назад.
4. **Не прятать LCP.** Заголовок и картинка первого экрана видны с первой отрисовки; анимация —
   сдвиг на 8–16 px, а не `opacity: 0` до выполнения JS.
5. **Reduced motion.** Уважать системную настройку: бесконечные анимации и автопрокрутка выключены,
   сдвиги заменены на короткие fade.
6. **Пауза вне экрана и на скрытой вкладке.** Никаких вечных `requestAnimationFrame` и интервалов.
7. **Hover-эффекты — только для `@media (hover: hover)`**: на тач-устройствах они «залипают».
8. **Токены движения** вместо разрозненных чисел:

| Токен           | Значение                     | Где                                  |
| --------------- | ---------------------------- | ------------------------------------ |
| `--motion-fast` | 120 мс                       | hover, нажатие                       |
| `--motion-base` | 200 мс                       | выпадающие списки, переключатели     |
| `--motion-slow` | 320 мс                       | появление блоков                     |
| `--motion-page` | 500 мс                       | переходы между страницами            |
| `--ease-out`    | `cubic-bezier(0.2, 0, 0, 1)` | появление                            |
| `--ease-in`     | `cubic-bezier(0.4, 0, 1, 1)` | исчезновение                         |
| spring          | stiffness 300, damping 30    | перетаскивание, «магнитные» элементы |

| **Мобильное меню**   | Fade + ступенчатое появление ссылок.                                                                                                                           | Оставить; добавить ловушку фокуса и закрытие при смене маршрута.                                                                                                                                                                                            |

### Техническая часть

- **framer-motion:** перейти на `LazyMotion` + `m` с `domAnimation` (≈ −30 КБ gzip из главного
  чанка) или вынести простые появления на CSS с маленьким хуком `useInView`; framer оставить там,
  где нужны пружины, жесты и layout-анимации.
- **Общие варианты** (`fadeUp`, `stagger`) — в одном модуле: сейчас похожие объекты объявлены
  отдельно в About, Page404, NavBar, Experience.
- **Scroll-driven animations** — под `@supports (animation-timeline: scroll())`, без полифилла.
- **Проверка:** запись Performance в DevTools с 4× CPU slowdown — ни одного long task от анимаций,
  ни одного «Layout» в кадре анимации.
